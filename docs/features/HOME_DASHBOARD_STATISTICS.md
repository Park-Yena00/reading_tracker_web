# 홈 화면 통계 대시보드 개편 설계서

## 1. 개요
기존의 정적인 홈 화면을 사용자의 독서 활동을 한눈에 파악할 수 있는 데이터 중심의 통계 대시보드로 개편합니다.

## 2. 주요 구성 요소

### 2.1 히어로 섹션 (Hero Section)
- **도서 검색 시작하기 버튼**: 유지
- **삭제 사항**: 소개글 (`hero-description`) 및 하단 이모티콘 섹션 (`features-section`) 삭제

### 2.2 통계 탭 시스템
- **위치**: 도서 검색 버튼 하단
- **탭 종류**: 일별 통계 (Daily) / 월별 통계 (Monthly) / 연별 통계 (Yearly)

## 3. 통계 상세 로직

### 3.1 일별 통계 (Daily) - 24시간 타임 트래커
- **UI**: 좌측 (24시간 축 타임 트래커) / 우측 (도서 정보 범례)
- **로직**:
    - 오늘 작성된 모든 메모를 수집
    - 도서별로 `min(memoStartTime)` ~ `max(memoStartTime)` 구간을 계산
    - 기존 인덱스 팔레트 색상을 순서대로 적용하여 타임라인 바 렌더링
- **범례**: 사용된 색상별로 도서명 및 저자명 표기

### 3.2 월별 통계 (Monthly) - 방치한 책 BEST 3
- **로직 (우선순위 기반 선출 및 순위 산정)**:
    1. **데이터 수집**: 내 서재의 모든 도서 정보와 `memo` 테이블의 도서별 최종 활동 시간(`MAX(memoStartTime)`)을 수집합니다.
    2. **1순위 (독서 활동 이력 있음)**:
        - 대상: 최소 1개 이상의 메모 레코드가 존재하는 도서.
        - 핵심 지표: **'최종 활동 경과 시간'** (현재 시간 - 가장 마지막 메모 작성 시간).
        - 순위 산정: 마지막 메모 작성 시간이 현재로부터 **과거로 가장 멀리 떨어진(오래된) 순서**대로 최대 3권을 선정합니다.
    3. **2순위 (독서 활동 이력 없음)**:
        - 대상: 메모 레코드가 0개이면서, 카테고리가 `Finished`(완독)가 아닌 도서.
        - 핵심 지표: **'서재 등록 경과 시간'** (현재 시간 - 서재 등록 일시).
        - 순위 산정: 1순위 그룹이 3권 미만일 경우, **등록일이 가장 오래된 순서**대로 남은 순위를 보충합니다.
    4. **제외 대상**: 이미 '완독'한 책은 방치된 도서 통계에서 제외합니다.
- **UI**: 중앙 집중형 리스트 카드 (순위 #1~#3 표시)

### 3.3 연별 통계 (Yearly) - 독서 요약 및 장르 분포
- **UI**: 좌측 (카테고리별 도서 수) / 우측 (장르별 통계 대시보드)
- **로직**:
    - **카테고리 집계**: 최근 1년 내 저장된 도서들의 `BookCategory`별 개수
    - **장르 집계 (트리맵 시각화)**:
        - **통계 대상**: 내 서재에 저장된 모든 도서를 대상으로 집계합니다.
        - **장르 추출 규칙**: `mainGenre` 필드의 전체 경로 문자열을 '>' 구분자로 분리하여 처리합니다.
            1. **기본 규칙**: 앞에서부터 순서대로 **3번째 장르**만 추출하여 표기합니다. (예: `국내도서>소설/시/희곡>한국소설>...` → **'한국소설'**)
            2. **보충 규칙**: 장르 세분화가 3단계 미만인 경우, 해당 경로의 **가장 마지막 장르**를 추출합니다. (예: `국내도서>컴퓨터/모바일` → **'컴퓨터/모바일'**)
        - **데이터 그룹화**: 추출된 장르명이 동일한 도서들을 하나의 그룹으로 묶어 합산된 권수를 계산합니다.
        - **시각화**: 전체 장르 분포를 비중에 비례한 원의 크기를 가지는 **버블 차트(Bubble Chart)** 대시보드로 나타냅니다. 각 버블 내부에는 '장르명 권수' 형태로 표기하며, 마우스 호버 시 강조 효과를 제공합니다.

## 4. 기술 구현 및 아키텍처

### 4.1 데이터 소스
- `memoService.getTodayFlow`: 일별 통계 데이터
- `bookService.getBookshelf`: 전체 도서 목록 (방치/연별 통계용)
- `memoService.getRecentBooks`: 활동 이력 도서 (방치 통계용)

### 4.2 아키텍처 규칙 준수
- **View-Helper 분리**: 통계 계산 로직은 `js/utils/statistics-helper.js`에서 순수 함수로 관리
- **ViewModel 패턴**: API 응답을 UI 렌더링에 적합한 데이터 객체로 가공 후 View에 전달
- **디자인 시스템**: `variables.css`의 색상 변수 및 팔레트 고수
