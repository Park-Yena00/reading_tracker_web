# 연별 통계: 메인 장르별 분포 집계 및 시각화 로직 개선 보고서

## 1. 문제 상황 및 개요
홈 화면의 연별 통계 중 **"메인 장르별 분포"** 기능이 사용자의 기대를 충족하지 못하는 정밀도로 집계되고 있었습니다. 특히 장르의 전체 경로가 모두 표시되어 가독성이 떨어지고, 동일한 상위 장르임에도 세부 장르가 달라 별개로 집계되는 이슈가 있었습니다.

## 2. 로직 비교 분석 (Before vs. After)

| 구분 | 이전 로직 (Before) | 개선된 로직 (After) |
| :--- | :--- | :--- |
| **통계 대상** | 올 한 해 독서를 시작한 도서 일부 | **내 서재에 저장된 모든 도서** |
| **장르 추출** | `mainGenre` 전체 경로 문자열 사용 | **3번째 수준의 장르** 추출 (Split & Extract) |
| **보충 규칙** | 규칙 없음 (전체 경로 그대로 표시) | 3단계 미만 시 **가장 마지막 장르** 추출 |
| **그룹화 방식** | 전체 경로가 일치해야 동일 장르로 간주 | **추출된 3단계 장르명이 같으면 통합 집계** |
| **시각화 방식** | 단순 리스트 또는 TOP 5 막대 그래프 | 데이터 비중에 비례한 원의 크기를 가지는 **버블 차트(Bubble Chart)** |
| **레이아웃 비중** | 좌측(카테고리) 1.5 : 우측(장르) 1.0 | **좌측 0.8 : 우측 1.2** (장르 대시보드 확장) |

## 3. 구체적인 개선 내용

### 3.1 장르 집계 엔진 고도화 (`statistics-helper.js`)
문자열 파싱 로직을 추가하여 데이터의 의미론적 그룹화를 실현했습니다.
*   **추출 규칙**: `split('>')`을 통해 배열화한 후, 인덱스 2(3번째)를 대표 장르명으로 선정.
*   **데이터 통합**: 이전에는 '한국소설>2000년대'와 '한국소설>고전'이 따로 집계되었으나, 현재는 **'한국소설'**이라는 하나의 데이터 블록으로 합산되어 정확한 비중을 보여줍니다.

### 3.2 버블 차트(Bubble Chart) 시각화 도입 (`home-view.js`, `home.css`)
단순한 수치 나열에서 벗어나 시각적 직관성과 역동성을 극대화했습니다. (초기 트리맵 설계에서 버블 차트로 최종 변경됨)
*   **비례적 크기 설계**: 가장 많은 권수를 가진 장르를 기준으로 각 장르의 버블 크기를 동적으로 계산합니다. (최소 80px ~ 최대 160px)
*   **애니메이션 효과**: 각 버블에 `floating` 애니메이션을 적용하여 살아있는 듯한 대시보드 느낌을 구현했습니다.
*   **표기 형식 최적화**: 원형 블록 내부에 **'장르명 권수'** 형태로 정보를 압축하여 표기합니다.

### 3.3 사용자 경험 중심의 레이아웃 조정
*   상대적으로 정보량이 적은 카테고리 원형 그래프(좌측)의 폭을 줄이고, 방대한 장르 데이터를 담아야 하는 버블 차트(우측) 공간을 **1.2배 확장**하여 시각적 답답함을 해소했습니다.

### 3.4 버블 겹침 방지(Non-overlap) 레이아웃 개선 (`home-view.js`, `home.css`)
버블 차트는 (완독률, 평점)이라는 좌표를 기반으로 배치되기 때문에, 장르가 여러 개이거나 권수 기반으로 버블이 커질수록 **버블끼리 겹치는 현상**이 자연스럽게 발생할 수 있습니다.  
이를 해결하기 위해 **외부 라이브러리 없이** 다음 방식으로 배치를 개선했습니다.

*   **목표 좌표(Target) 유지**: 각 버블은 여전히
    *   X축 = 완독률(0~100%)
    *   Y축 = 평균 평점(0~5점)
    를 기준으로 “가야 할 위치(tx, ty)”를 갖습니다.
*   **권수 기반 크기 반영(비례 스케일)**: 버블 크기는 장르별 보유 권수(`count`)가 많을수록 커지도록 하되, UI 안정성을 위해 지름을 **최소~최대 범위**로 제한하고(기본 80px~160px), 권수는 **sqrt 스케일**로 변환하여 극단적 쏠림을 완화했습니다.
*   **충돌 해소(force/packing) 시뮬레이션**: 렌더 직후 캔버스의 실제 픽셀 크기를 기준으로
    *   버블 간 거리가 \((r_1 + r_2 + padding)\) 보다 가까워지면 서로 밀어내고,
    *   동시에 목표 좌표로 약하게 끌어당겨(Attraction) “의미 있는 좌표”를 최대한 유지하며,
    *   캔버스 바깥으로 나가지 않도록 경계(clamp)를 적용했습니다.
*   **공간 부족 시 자동 축소(안전장치)**: 충돌이 해소되지 않을 정도로 공간이 부족한 경우, 전체 버블 반지름을 단계적으로 소폭 축소하여 **겹침이 없도록** 보장했습니다. (단, 최소 반지름은 유지)
*   **CSS transform 충돌 제거**: 버블은 JS로 `left/top(px)` 좌표를 고정하고, CSS 애니메이션/호버는 `translate(-50%, -50%)` 기준으로만 동작하도록 수정하여 **레이아웃 계산이 흔들리지 않도록** 했습니다.

## 4. 결과 및 기대 효과
*   **데이터 유의미성 확보**: 파편화되어 있던 장르 데이터를 상위 카테고리 기준으로 묶어 보여줌으로써 사용자의 실제 독서 취향을 더 정확하게 반영합니다.
*   **정보 전달력 강화**: 버블 차트 시각화를 통해 어떤 장르를 가장 많이 읽었는지 한눈에 파악할 수 있으며, 확장된 레이아웃을 통해 더 많은 장르 정보를 쾌적하게 열람할 수 있습니다.

## 5. 버블 차트 좌표계 변수 조합 추천 및 설정

버블의 위치를 X축과 Y축으로 지정하여 보다 입체적인 독서 분석을 제공하기 위한 3가지 추천 조합입니다.

| 추천 조합 | X축 (가로) | Y축 (세로) | 분석 목적 |
| :--- | :--- | :--- | :--- |
| **조합 1: 완독성 vs 만족도** | **완독률 (Completion Rate)** | **평균 평점 (Avg Rating)** | 가장 선호하는 '인생 장르' 식별 |
| **조합 2: 습득량 vs 활동성** | **평균 독서 진척도 (%)** | **최근 활동성 점수** | 현재 뜨겁게 읽고 있는 '열독 장르' 분석 |
| **조합 3: 관심사 역사 vs 밀도** | **평균 서재 등록 기간** | **권당 평균 페이지 수** | 장기적 관심사와 '학술적 장르' 깊이 분석 |

### [최종 적용] 추천 조합 1: 완독률 VS 평점
- **X축(완독률)**: (장르별 완독 도서 수 / 해당 장르 도서 수) * 100
- **Y축(평점)**: 해당 장르 도서들의 부여 평점 평균 (1~5점)
- **버블 크기**: 해당 장르의 보유 도서 권수
- **배치 의미**: 우상단으로 갈수록 사용자가 많이 완독하고 높은 만족도를 느끼는 핵심 장르임을 의미합니다.
